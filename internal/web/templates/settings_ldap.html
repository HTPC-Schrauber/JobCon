LDAP / Active Directory Server

Zentrale Anbindung an Microsoft Active Directory oder OpenLDAP zur Authentifizierung von JobCon-Benutzern.

{{if .LDAPConfig.Enabled}} Aktiviert {{else}} Deaktiviert {{end}}

Anmeldeverfahren (Direct User Bind & Service Account)

JobCon unterstützt die direkte Benutzeranmeldung (Direct User Bind) ohne separaten Bind-Benutzer.

Betrieb ohne Service-Account (Direct User Bind)

Wenn Sie keinen Bind-Benutzer (Service Account) konfigurieren möchten, lassen Sie Bind-DN einfach leer. JobCon bindet sich direkt mit den Zugangsdaten des Benutzers an das Verzeichnis (z. B. via UPN benutzer@firma.de) und liest im Anschluss die konfigurierten Attribute aus.

Muster zur Bildung der Anmelde-Identität. %s wird durch den Loginnamen ersetzt. Wenn leer, leitet JobCon den Domain-Suffix automatisch aus der Suchbasis (DC=...) ab.

Optional: Fester Bind-Benutzer (Service Account)

Suchbasis & Attribut-Herkunft (Mapping)

Globale Festlegung der LDAP/AD-Attribute für Loginname, Vorname, Nachname und E-Mail. Gilt für alle LDAP-Benutzer in JobCon.

Ausgangs-DN, unter dem nach Benutzern gesucht wird.

Optionaler LDAP-Filter (z. B. (&(objectClass=user)(sAMAccountName=%s))). %s wird durch den Loginnamen ersetzt.

Attribut-Zuordnung im Verzeichnisdienst

AD: sAMAccountName / OpenLDAP: uid

Standard: givenName

Standard: sn

Standard: mail

LDAP / AD Benutzer-Lookup testen

Prüfen Sie, wie ein Benutzer im Active Directory aufgelöst wird und welche Attribute (Vorname, Nachname, E-Mail) bezogen werden.

Wenn Sie ohne Service Account arbeiten, geben Sie hier das Passwort an, um den direkten Login zu verifizieren.
